
## Project Overview

This project is a beginner-level data quality audit completed in Microsoft Excel.

The main aim for the project was to inspect an employee dataset, identify common data-quality problems, and create cleaned versions of important fields without modifying the original raw data.
The project focuses on practical data-cleaning skills that are commonly used by data analysts.


## Dataset

The dataset contains info on:

- Employee ID
- Employee Name
- Country
- Department
- City
- Age
- Annual Salary
- Employment Type

The dataset contains intentional data-quality issues such as:

- Missing values
- Inconsistent capitalization
- Extra spaces
- Inconsistent country formats
- Inconsistent department names
- Inconsistent city names
- Different salary formats
- Inconsistent employment types
- Potential duplicate records
- Potential invalid values

## Project Objectives

The main objectives were to:

1. Inspect the dataset for data-quality problems.
2. Identify missing values.
3. Identify possible duplicate records.
4. Clean employee names.
5. Standardize country names.
6. Standardize department names.
7. Clean city names.
8. Review and clean age values.
9. Convert salary values into a consistent numerical format.
10. Standardize employment types.
11. Compare the original data with the cleaned data.


## Excel Techniques Used

The project uses several Excel functions and features, including:

- `TRIM()`
- `PROPER()`
- `IF()`
- `OR()`
- `ISNUMBER()`
- `VALUE()`
- `SUBSTITUTE()`
- `RIGHT()`
- `COUNTIF()`
- `XLOOKUP()`

These functions were used to clean text, identify missing values, standardize categories, and convert salary values into a usable numerical format.
